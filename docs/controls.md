# 조작법

## 기본 조작

| 상황 | 키 | 동작 |
|---|---|---|
| 글자가 써지는 중 | **F** | 대사를 한 번에 모두 표시 (`prevent-skip: true` 면 불가) |
| 대사가 다음 페이지로 이어짐 | **F** | 다음 페이지 |
| 선택지가 나옴 | **숫자키 1~6** | 해당 번호 선택지로 커서 이동 (맨 위로 스크롤) |
| 선택지가 나옴 | **마우스 휠** | 커서 위/아래 한 칸 |
| 선택지가 나옴 | **F** | 커서가 있는 선택지로 결정 |
| 마지막 대사 | **F** | 대화 닫기 |
| 언제든 | **웅크리기(Shift)** | 대화 종료 (`exit: None` 이거나 종료 금지 대화면 불가) |

숨은 보조 입력 (안내 문구에는 나오지 않음):

- **W / S** : 선택지 커서 위/아래 (`select-keys: true`)
- **Space** : 선택지 결정 (`select-keys: true`)

> F키는 "양손 바꾸기" 키입니다. 키를 바꿔 쓰는 플레이어는 바꾼 키를 누르면 됩니다.
> 대화 중에는 손 바꾸기, 아이템 버리기, 클릭/공격이 막힙니다.

### 선택지가 3개보다 많을 때

선택지 창에는 한 번에 3개(`layout.yml` 의 `Answer-Lines.count`)만 보입니다.
숫자키를 누르면 **그 선택지가 맨 위로 올라가고** 아래에 숨어 있던 선택지가 보입니다.

```
선택지 1~4, 처음 화면      2 를 누르면            1 을 누르면
 ▶ 1. 방을 빌릴게요          ▶ 2. 소문 있어?         ▶ 1. 방을 빌릴게요
   2. 소문 있어?               3. 식사 되나요?          2. 소문 있어?
   3. 식사 되나요?             4. 안녕히 계세요         3. 식사 되나요?
```

마지막 선택지들은 창이 비지 않도록 끝에 맞춰집니다 (선택지 4개에서 4 를 눌러도 2·3·4 가 보임).
W/S 로 움직일 때는 커서가 창 밖으로 나갈 때만 한 칸씩 스크롤됩니다.

### 숫자키가 동작하는 원리

선택지가 떠 있는 동안 플레이어가 손에 든 핫바 칸이 **8번 칸으로 고정**됩니다. 대화가 끝나면 원래 칸으로 돌아갑니다.

- 서버는 "숫자키를 눌렀다"와 "휠을 굴렸다"를 구분해서 받지 못하고, 둘 다 "핫바 칸이 바뀌었다"로만 받습니다.
- 8번 칸에 있을 때 휠을 굴리면 항상 7번(위) 또는 9번(아래) 칸으로 바뀝니다.
  그래서 7·9번은 휠로, 1~6번은 숫자키로 처리해 **둘을 동시에** 쓸 수 있습니다.
- 이미 들고 있는 칸(8번)의 숫자키는 서버에 신호가 오지 않으므로 8번 키는 동작하지 않습니다.
  7번 키는 휠 위, 9번 키는 휠 아래와 같습니다.

따라서 숫자키로 바로 고를 수 있는 선택지는 **6개까지**입니다
(그 이상은 휠 또는 W/S 로 이동).

## 입력 방식 바꾸기 (`config.yml`)

```yaml
Settings:
  # 진행/결정 입력. F키(SwapHand)는 항상 켜져 있고, 클릭을 추가할 수 있음
  interaction: [SwapHand]          # 예) [SwapHand, LeftClick]
  exit: Sneak                      # Sneak / None
  select-keys: true                # W/S 이동 + Space 결정
  hotbar: Number                   # Number / Scroll / None
  scroll-cooldown: 2               # Scroll 모드 입력 간격 (tick)
  click-cooldown: 4                # F/클릭 연타 방지 (tick)
```

| `hotbar` | 동작 |
|---|---|
| `Number` (기본) | 숫자키 1~6 + 마우스 휠 동시 사용, F로 결정. 선택 중 8번 칸 고정 |
| `Scroll` | 마우스 휠만 사용 |
| `None` | 핫바 입력을 대화에 쓰지 않음 |

> **우클릭은 권장하지 않습니다.** 빈손으로 허공을 우클릭하면 클라이언트가 서버에 아무 패킷도 보내지 않아서 인식이 안 됩니다.

입력 방식을 바꾸면 스타일 파일의 안내 문구(`Texts`)도 맞게 고쳐 주세요 → [스타일](styles.md#texts)
